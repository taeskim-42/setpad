# 타이머 실기기 체크리스트 (1.8.0)

명세 `docs/timer-redesign-1.8.md` §5 의 네이티브 동작을 실기기에서 확인하는 목록이다. 시뮬레이터·에뮬레이터로는 잠금·전화·블루투스·무음 스위치를 볼 수 없다.

준비: 운동 칸 이름을 `버피 타바타 20/10 x3 60bpm` 으로 두고 [▶ 시작]. 박자만 볼 때는 `스쿼트 60bpm`. 소리 크기는 중간, 음악 앱은 끈 상태에서 시작한다(6·12번만 켠다).

## 녹음 음성 — 시스템 음성(TTS) 대신

세는 말과 구간 음성은 모두 녹음 파일이다(ElevenLabs, 영어, 남 Liam·여 Laura). 세는 말 1~100 은 `tool/make_count_voices.py` 로 만들었고, 구간 음성은 Tempo 의 것을 그대로 가져왔다(`assets/voice`). 시스템 음성은 어디에서도 나오지 않는다.

숫자 녹음은 0.5~1.25초라 빠른 박자에서는 박마다 다 읽을 수 없다. 기기(iOS·Android·웹 같은 규칙)는 숫자를 클릭 반 박 뒤에 내고, 앞 말이 아직 나오면 1/4박까지 기다렸다가 넘으면 버린다. 말의 끝은 녹음 길이로 잰다(iOS 도 재생 상태가 아니라 길이 — 재생 상태는 마지막 소리 뒤 0.1초쯤 더 켜져 있다). 앱은 그 기다림 안(40ms 여유)에 들어오는 동안 박마다 세고, 넘기 직전에 둘마다, 더 길어지면 다섯·열마다로 넓힌다(좁아지지는 않는다). 넓힌 뒤의 숫자는 앞 말이 끝난 뒤 제때 난다. One 은 늘 읽어 시작을 알리므로 세는 동안 "Go!"·라운드 말은 없다. 기본값 60bpm 은 남녀 모두 목표 30 까지 박마다, 목표 없이 세면 Forty-six 뒤부터 둘마다 — `countsSaid`, 길이 표는 `lib/count_voice_lengths.dart`.

준비: 설정 → "박자를 소리내어 세기" 켬, "목소리" 남자, "운동 음성 안내" 켬.

## iOS 백그라운드 — 로컬 알림 (무음 keep-alive 대신)

iOS 는 들리는 소리를 내는 동안만 audio 백그라운드 모드를 쓴다(박자 클릭·세는 말). 소리 없는 구간에 앱을 깨워 두려고 무음을 재생하지 않는다. 그 대신 앱이 백그라운드로 갈 때 운동 run 의 다음 구간 시작들(최대 40개, 앱 전체 대기 알림 64개 안에서 휴식 몫 1개를 남기고)을 로컬 알림으로 예약하고, 돌아오면 모두 지운다. 알림 시각은 정수 초로 올려 잡는다(이르게 울리지 않는다, 최대 1초 늦음). 알림 소리는 앱의 녹음 목소리(CAF 로 바꿔 Library/Sounds 에 둔다)다. 실제 iPhone 에서 본다 — 시뮬레이터는 잠금·무음 스위치·알림 소리를 제대로 볼 수 없다.

준비: 앱을 지우고 새로 설치. 운동 음성 안내 켬, 목소리 남자, 박자 세기 끔.
