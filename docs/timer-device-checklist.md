# 타이머 실기기 체크리스트 (1.8.0)

명세 `docs/timer-redesign-1.8.md` §5 의 네이티브 동작을 실기기에서 확인하는 목록이다. 시뮬레이터·에뮬레이터로는 잠금·전화·블루투스·무음 스위치를 볼 수 없다.

준비: 운동 칸 이름을 `버피 타바타 20/10 x3 60bpm` 으로 두고 [▶ 시작]. 박자만 볼 때는 `스쿼트 60bpm`. 소리 크기는 중간, 음악 앱은 끈 상태에서 시작한다(6·12번만 켠다).

| # | 항목 | 하는 법 | 기대 결과 |
|---|---|---|---|
| 1 | 잠금 중 소리 (iOS) | 운동 구간에서 전원 단추로 잠근다. 휴식·다음 라운드까지 2분 둔다. | 클릭·세는 말·구간 신호음이 잠금화면에서도 계속 나온다. 휴식(소리 없는 구간) 뒤 다음 운동 신호음이 제때 난다(keep-alive). 풀면 숫자가 실제 경과 시간 자리에 있다. |
| 2 | 제어 센터·알림 센터·Face ID 뒤 계속 (iOS) | 실행 중 제어 센터를 내렸다 닫고, 알림 센터를 내렸다 닫고, 잠갔다 Face ID 로 연다. | 어느 경우에도 일시정지되지 않고 소리가 끊기지 않는다(`willResignActive` 관찰 삭제). |
| 3 | 전화 뒤 자동 재개 (iOS) | 실행 중 다른 폰으로 전화를 걸어 받고, 끊는다. 한 번은 거절도 해 본다. | 전화가 오면 타이머가 일시정지된다(`interrupted`). 통화가 끝나 시스템이 재개를 허락하면(`shouldResume`) 저절로 이어 간다(`resumed`). 재개 허락이 없으면 일시정지로 남고 [계속] 으로 이어 간다. 일시정지 중 손으로 재개했으면 나중에 온 재개 신호는 아무 일도 하지 않는다. |
| 4 | Android 화면 끄고 2분 뒤 자리·소리 | 실행 중 전원 단추로 화면을 끈다. 2분 뒤 켠다. 홈 버튼으로 나갔다 2분 뒤 돌아오기도 한다. | 일시정지되지 않는다(`onPause` 의 interrupt 삭제). 켜면 숫자가 실제 경과 시간 자리에 있다(벽시계 보정). 꺼진 동안 소리는 기기·Doze 에 따라 늦거나 빠질 수 있다 — 빠진 큐는 다시 울리지 않는다(의도, 포그라운드 서비스는 1.8.1). 들린 것/빠진 것을 기기 이름과 함께 적는다. |
| 5 | 블루투스 이어폰 | 이어폰을 연결하고 시작, 도중에 이어폰을 뺀다(케이스에 넣는다). | 소리가 이어폰으로 나온다. 빼면 폰 스피커로 넘어가거나 멈추는데, 어느 쪽이든 타이머 숫자는 계속 간다. 앱이 죽거나 타이머가 멈추면 실패. |
| 6 | 무음 스위치 (iOS) | 무음 스위치를 켜고 시작. | 소리가 난다 — `.playback` 범주는 무음 스위치를 무시한다(의도: 바닥에 둔 폰의 신호가 생명). 음악 앱을 틀어 둔 상태면 음악 위에 섞여 들리고 음악이 멈추지 않는다(`.mixWithOthers`). |
| 7 | 설치 뒤 첫 실행 준비 3초 안에 "One·Two" | 앱을 지우고 새로 설치, 로그인 뒤 첫 박자 타이머 시작(박자 세기 켬). | 준비 3초가 끝나고 첫 박부터 "One·Two·Three" 가 빠지지 않는다(편집기가 타이머 칸을 보여 줄 때 `warmUp` 이 큐 플레이어와 첫 녹음 — 두 목소리의 1~10, Go!·Rest! — 를 미리 올린다). 첫 신호음이 두 번째보다 늦지 않다. `warmUp` 자체는 소리를 내지 않고 음악을 줄이지 않는다. |
| 8 | 앱 언어와 상관없이 영어 녹음 | 기기 언어를 한국어·简体中文·日本語 로 바꿔 각각 박자 타이머 시작(박자 세기 켬). | 어느 언어든 같은 영어 녹음("One, Two…")으로 센다. 시스템 음성(기계 목소리)이 한 마디라도 나오면 실패. |
| 9 | 잠금 중 진동 없음 (iOS·Android) | 1번 상태에서 진동을 느껴 본다. | 화면이 켜져 있을 때만 진동한다. 잠금 중에는 진동이 없고 소리만 난다(의도 — 햅틱은 화면 켜짐의 보조, 원칙 7). |
| 10 | 끝나는 말 안 끊김 | 박자 목표 5회로 시작해 끝까지 둔다(박자 세기 켬). 타바타는 마지막 라운드까지 둔다. | 마지막 숫자("Five")가 끝까지 들리고 완료 신호음 뒤 "Workout complete, great job!" 이 난다. 일시정지·종료를 누르면 말이 바로 끊긴다. |
| 11 | Android 전화 | 실행 중 전화를 받는다. | 이번 판에는 통화 감지가 없고 오디오 포커스도 잡지 않는다 — 타이머는 계속 돌고 소리가 통화에 섞일 수 있다(알려진 한계, 1.8.1). 결과를 적는다. |
| 12 | 다른 앱 음악 (Android) | 음악을 틀고 시작. | 음악 소리가 줄거나 멈추지 않는다(오디오 포커스를 잡지 않는다). |
| 13 | 화면 켜 둠 | 잠그지 않고 실행 중 자동 잠금 시간보다 오래 둔다. | 화면이 꺼지지 않는다(iOS `isIdleTimerDisabled`, Android `FLAG_KEEP_SCREEN_ON`). 일시정지·완료 뒤에는 원래대로 꺼진다. |
| 14 | 심사 노트 (iOS) | App Store Connect 의 심사 노트(App Review Information → Notes)에 적는다. | 문구: "타이머 신호음·박자 세기를 잠금화면에서도 내기 위한 오디오 재생" (영문 병기: "Audio playback so the timer's interval cues and spoken beat count keep sounding on the lock screen."). 1번 확인 영상을 같이 첨부하면 좋다. |
| 15 | keep-alive 반려 시 | 심사가 백그라운드 오디오(2.5.4)로 반려하면 | `ios/Runner/TimingBridge.swift` 의 `private static let keepAliveLoop = true` 를 `false` 로 바꿔 다시 낸다. 그러면 소리 없는 구간(휴식)에 앱이 멈출 수 있고, 돌아오면 숫자가 제자리를 찾으며 놓친 신호는 울리지 않는다(Tempo 방식). 바꾼 뒤 1번을 다시 확인한다. |

## 세트 무대(운동 화면) — 1.8.0

준비: 오늘 기록에 `벤치프레스` 칸(세트 하나 이상)을 두고 노트 막대 [▶](운동 화면)로 연다. 설정의 "세트 사이 휴식 기본" 은 1:30.

| # | 항목 | 하는 법 | 기대 결과 |
|---|---|---|---|
| 16 | 휴식 끝 소리 | [했어요] 뒤 휴식을 끝까지 둔다(화면 켠 채). | 남은 3·2·1초에 띠 소리와 흰 깜빡임, 0초에 끝 소리(딩)가 잘리지 않고 나며 다음 세트 화면으로 돌아온다. 진동 설정이 켜져 있으면 진동도 난다. |
| 17 | 잠금 중 휴식 끝 알림 | [했어요] 뒤 바로 전원 단추로 잠근다. | 휴식이 끝나는 때에 잠금 화면 알림("휴식 끝 · 다음 · N세트 …")이 뜬다. iOS 는 끝 소리도 난다(keep-alive). 처음 무대를 열 때 알림 권한을 한 번 묻는다 — 거절했으면 알림 없이 소리만. |
| 18 | 무대가 열린 동안 화면 켜 둠 | 무대를 연 채(휴식이 아닌 다음 세트 화면) 자동 잠금 시간보다 오래 둔다. | 화면이 꺼지지 않는다. 무대를 접으면 원래대로(타이머가 돌고 있지 않다면) 꺼진다. 휴식이 끝나도 무대가 열려 있으면 계속 켜져 있다. |
| 19 | 타이머와 휴식이 서로 끄지 않음 | 타바타를 돌리다 접고, 다른 칸에서 세트 무대 [했어요] → 휴식, 그동안 타바타가 끝나게 둔다. | 타바타가 끝나도 휴식 카운트다운·화면 켜 둠이 이어진다. 타바타가 도는 동안 휴식 신호음은 나지 않는다(타이머 우선, 눈으로만). |
| 20 | 대신 적기로 갔다 와도 그대로 | 휴식이 도는 중 ⋯ → 대신 적기 → 내 기록으로. | 휴식 띠·카운트다운·타이머가 그대로다(내 편집기를 뒤에 살려 둔다). |
| 21 | 심박 회복 신호 | 워치를 찬 채 세트를 하고 [했어요], 휴식 중 심박이 내려오게 둔다(건강 권한이 이미 있을 때만). | "♥ 132 → 107" 줄이 보이고, 회복하면 줄이 "심박이 돌아왔어요 · 바로 다음 세트" 로 바뀌며 진동이 한 번 난다(소리 없음). 권한 창을 새로 띄우지 않는다. |
| 22 | 기록을 닫을 때 묻기 | 타바타가 도는 중 [완료]/뒤로를 누른다. 끝났지만 안 적은 타바타가 있을 때도 누른다. | 도는 중이면 "도는 타이머를 멈추고 나갈까요?", 안 적은 run 이 있으면 [먼저 적기][버리고 나가기][취소]. |

## 녹음 음성 — 시스템 음성(TTS) 대신

세는 말과 구간 음성은 모두 녹음 파일이다(ElevenLabs, 영어, 남 Liam·여 Laura). 세는 말 1~100 은 `tool/make_count_voices.py` 로 만들었고, 구간 음성은 Tempo 의 것을 그대로 가져왔다(`assets/voice`). 시스템 음성은 어디에서도 나오지 않는다.

준비: 설정 → "박자를 소리내어 세기" 켬, "목소리" 남자, "운동 음성 안내" 켬.

| # | 항목 | 하는 법 | 기대 결과 |
|---|---|---|---|
| 23 | 세기 One~One hundred, 101 부터 무음 | `스쿼트 60bpm` 목표 105 로 시작해 끝까지 둔다. | 박마다 클릭 뒤 반 박에 "One"…"One hundred" 가 녹음 목소리로 난다. 101 부터는 말 없이 클릭만 간다. 기계 목소리가 나오면 실패. |
| 24 | 빠른 박자 | `스쿼트 120bpm` 을 30초 둔다. | 숫자끼리 겹쳐 읽지 않는다. 다음 클릭을 넘기는 긴 숫자(Seventy-seven 등) 뒤의 숫자는 건너뛴다(알려진 한계 — 녹음은 빨리 읽지 못한다). 들린 것과 빠진 것을 적는다. |
| 25 | 타바타 구간 음성 | `버피 타바타 20/10 x3`(박자 없음)를 끝까지 둔다. | 운동 시작마다 "Round 1, go!"·"Round 2, …"·마지막 "Last round, finish strong!", 휴식마다 "Rest!", 끝에 "Workout complete, great job!". 신호음이 끝난 뒤에 말한다. 예전의 "N라운드 종료" 기계 음성은 없다. |
| 26 | 박자 세기와 구간 음성 | `버피 타바타 20/10 x3 60bpm`, 세기 켬. | 운동 시작에는 라운드 말 없이 첫 숫자 "One" 이 시작을 알린다(숫자와 겹치지 않게). 휴식 "Rest!", 끝 "Workout complete". |
| 27 | 남·여 | 설정 "목소리" 를 여자로 바꾸고 23·25번. | 세는 말과 구간 음성이 모두 여자 목소리다. |
| 28 | 운동 음성 안내 끔 | 설정에서 끄고 25번, 세트 무대 휴식. | 구간 음성과 휴식 음성이 없다. 세는 말은 "박자 세기" 설정대로 난다. |
| 29 | 세트 무대 휴식 | 휴식 1:30 으로 [했어요] 뒤 끝까지 둔다. 휴식 20초로도 한 번. | 남은 10초에 "Ten seconds!", 0초 딩 뒤 "Go!". 30초 미만 휴식에는 "Ten seconds!" 가 없다. 타바타가 도는 동안에는 휴식 음성도 없다(19번). |
| 30 | 음악 위에 섞임 | 음악 앱을 틀고 23·25번. | 녹음 목소리가 음악 위에 섞여 들리고 음악은 줄거나 멈추지 않는다(iOS `.mixWithOthers`, Android 오디오 포커스 없음). Android 는 신호음과 같은 미디어 볼륨으로 나오고, 무음·진동 모드에서도 목소리만 빠지지 않는다. |
| 31 | 잠금 중 | 1번처럼 잠근 채 25·29번. | 잠금 화면에서도 세는 말·구간 음성·휴식 음성이 난다. |
| 32 | 멈춤·다시 켬 | 말하는 도중 일시정지, 다시 [계속]. | 말이 바로 끊기고, 이어 갈 때 그 구간의 말을 되풀이하지 않는다. 같이 하기에서 자리를 다시 맞출 때도 같은 말을 두 번 하지 않는다. |
