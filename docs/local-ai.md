# 한 줄 운동 설정

운동 이름 칸에 무게·횟수·목표가 포함된 문장을 입력하고 엔터를 누르면, 사용 가능한 기기 내 모델로 운동 설정을 추출한다. 원문과 편집 가능한 모든 숫자·단위를 먼저 보여주고 확인 후 적용한다. 취소하면 원문을 보존하고 기록을 만들지 않는다. 이름만 입력하면 일반 운동 블록으로 저장하며 모델에 운동 계획을 생성시키지 않는다. 서버 AI를 호출하지 않는다. 운동 검색 결과를 직접 선택하면 기존 입력을 사용한다. [숫자 정확성 계약](numeric-accuracy.md)을 따른다.

## 검색과 기록

- 로컬 운동 사전과 사용 이력에서 입력과 관련된 후보를 최대 8개 검색해 모델의 지시문에 전달한다. iOS와 Android 모두 같은 후보를 받는다. 임베딩 검색을 사용하는 구성은 아니다.
- 최근 사용한 이름은 별도 설정 파일에 보관하므로 기록을 삭제하거나 앱을 재실행해도 추천 목록에 남는다. 같은 검색 정확도에서는 최근 사용한 이름이 먼저 나온다.
- 띄어쓰기, 단어 순서, 초성, 오타 검색은 모델 사용 가능 여부와 무관하게 동작한다.
- 운동 블록 오른쪽 이동 손잡이로 세트와 메모를 함께 옮긴다. 미완료 세트의 숫자에는 취소선을 표시하지 않는다.
- 이동 중에는 모든 블록의 기록을 접어 제목만 표시하고, 이동 완료·취소 시 다시 펼친다. 제목을 누르면 운동명을, 세트 번호나 값을 누르면 해당 세트를 수정한다. 수정 시 메모·완료 상태·입력 중인 초안은 유지한다.
- 세트가 없는 운동도 계획으로 저장한다. 미확정 입력은 편집 위치와 함께 드래프트로 보존하며, 완료 세트로 임의 변환하지 않는다.
- 설정에서 앱 기본 무게 단위(kg/lb)를 고른다. 새 운동에 적용하며 기존 기록의 숫자와 단위는 유지한다.
- 변경 후 400ms에 자동 저장하고, 화면 종료와 앱 백그라운드 전환 시 저장을 요청한다. 파일 쓰기를 순서대로 처리하고 임시 파일 교체로 기록 손상을 줄인다.

예: `벤치 80kg 100개 채우기` → 벤치프레스, 기본 무게 80kg, 총 목표 100회. 이후 `20`을 입력해 세트를 추가하면 80kg × 20회, 진행 상황 20/100회가 된다. 목표를 설정하는 것만으로 완료한 세트를 만들지는 않는다. 운동 이름 아래 설정 요약을 눌러 해석 결과를 수정할 수 있다.

## 안내

첫 실행 팝업 대신 운동 이름 입력 아래 `한 줄 설정`에 현재 상태를 표시한다. 탭하면 이유와 기본 입력 방법을 설명한다.

| 상태 | 안내와 동작 |
| --- | --- |
| 사용 가능 | 입력 예시와 기기 내 처리 설명 |
| Apple Intelligence 비활성 | 설정 → Apple Intelligence 및 Siri 안내 |
| iOS 버전 부족 | iOS 26 이상 및 지원 기기 필요 안내 |
| 지원하지 않는 iPhone | 기본 운동 입력 안내 |
| 모델 준비 중 | 준비 후 다시 확인 안내 |
| Android 모델 다운로드 가능 | 사용자가 ‘모델 준비’를 눌렀을 때만 다운로드 |
| 현재 언어 미지원 | 지원 언어로 변경 안내 |
| Android 서비스 사용 불가 | 일시적 준비 상태일 수도 있으므로 영구 미지원으로 단정하지 않음 |
| 웹 등 미지원 환경 | 기본 입력 및 지원 모바일 앱 안내 |

앱으로 돌아오면 상태를 다시 확인한다. 앱의 기존 최소 OS 요구사항은 유지하며, 모델 이용 가능 여부는 시스템 API로 판단한다.

## 실패 처리

- 입력 수정, 화면 종료, 백그라운드 전환 시 진행 중 해석을 취소한다.
- 해석 실패 시 원문을 유지하고 재입력 또는 ‘운동 이름으로 사용’을 제공한다.
- 결과의 필드 타입, 숫자 범위, 단위를 검증한다. 입력에 명시된 숫자가 결과에서 누락되면 적용하지 않는다.
- 총 목표, 세트당 횟수, 목표 세트 수를 구분해서 저장한다. 완료 표시된 세트만 목표 진행에 합산한다.
- 기존 기록과 메모는 그대로 읽는다. 잘못된 설정 메타데이터가 있어도 기존 세트 기록은 유지한다.

## 검증 기록 (2026-09-08)

Flutter 자동 테스트로 미지원 기기의 기본 기록, 비활성 안내와 앱 복귀, 명시적 다운로드, 기본 무게와 누적 목표, 저장 호환성, 실패 시 입력 보존, 늦게 도착한 응답 무시, 상태 확인 중 입력, 숫자 누락 거부를 검증했다.

현재 Mac의 실제 Foundation Models 모델에서 한국어 지원을 확인하고 아래 네 입력의 운동 이름·무게·각 목표 필드를 검증했다. 필수 숫자 필드와 `@Guide`를 사용하고 입력 문장을 그대로 전달한다. 없는 숫자는 네이티브 응답에서 0으로 생성한 뒤 앱 경계에서 null로 변환한다.

| 입력 | 기대 결과 |
| --- | --- |
| 벤치 80kg 100개 채우기 | 벤치프레스, 80kg, 총 100회 |
| 푸시업 총 백 개 | 푸시업, 무게 없음, 총 100회 |
| 벤치 팔십 키로로 백 개 채울래 | 벤치프레스, 80kg, 총 100회 |
| 스쿼트 60kg 10회 5세트 | 스쿼트, 60kg, 세트당 10회, 5세트, 총 목표 없음 |

네 예시는 모두 통과했다. iPhone 및 Android 실기기 추론은 아직 검증하지 않았다. 모델 버전·기기·언어·문장에 따라 결과가 달라질 수 있으며, 숫자 검증만으로 잘못된 의미 해석을 모두 발견할 수는 없다. 실기기에서는 위 예시와 사용자 정의 운동명, 설정 변경 후 복귀, 모델 미준비 상태를 추가 확인해야 한다.
