# 기록과 몸의 변화

iPhone 17e 시뮬레이터(390×844, iOS 26.5), 디버그 빌드. 30일치 가짜 기록: 아무것도 안 적은 날, 식단만 적은 날, 운동 소모량을 안 잰 날, 열량 미상이 섞인 날, 사흘에 한 번 잰 체중.

- `trends-30d-390x844.png` — 위는 kcal(섭취 막대·운동 막대·둘 다 있는 날의 섭취−운동 점), 아래는 kg(잰 날에만 점). 두 그래프가 같은 날짜 축을 쓴다. 빈 날은 비어 있고, 열량 미상이 섞인 날의 섭취 막대는 속이 비어 있다. 평균마다 제 분모(일수)가 붙는다.
- `day-summary-390x844.png` — 오늘 문서의 머리말 한 줄. 열량 미상이 있어 차이를 내지 않고 "확인된 섭취 … · 열량 미상 1건" 이라고 적는다. 오늘 잰 체중이 없으므로 체중 줄은 없다.

계산 정의와 누락 규칙은 `lib/daily.dart` 머리말, 자동 검증은 `test/daily_test.dart`·`test/trends_test.dart`.
