# 같이 하는 타이머 — 화면 확인 (2026-09-21)

위젯 테스트에서 390×844, 실제 한글 글꼴(AppleSDGothicNeo)로 그린 것이다. 아이콘 글꼴은
싣지 않아 네모로 나온다. **실기기 화면이 아니다** — 두 폰의 소리가 얼마나 어긋나는지는
여기서 알 수 없고, 실기기 두 대로만 확인된다.

1. `1-invite.png` — 상대의 제안. 받기 전에는 내 기록에 아무것도 생기지 않는다.
2. `2-accepted-their-turn.png` — 교대에서 뒤에 하는 사람. 내 차례까지 남은 초를 센다.
3. `3-rest-count-entry.png` — 쉬는 구간의 한 번에 적기와 상대의 횟수.
4. `4-logged-partner-left.png` — 적은 횟수는 내 기록의 세트로 남는다. 상대가 멈춘 자리.

실서버(격리된 e2e 서버, 한 기계) 에서 두 폰이 각자 계산한 자리의 차이: 1~2ms
(`integration/timer_server_test.dart`). 실제 그물에서의 값은 재지 못했다.
